# Dashboard de Reporting Commercial "Opérateur télécom SFR" (Excel)

## Contexte Métier
Création d'un tableau de bord complet pour un opérateur télécom (SFR) afin de suivre les indicateurs de performance clés liés aux clients, au réseau et aux ventes. Ce projet démontre ma maîtrise d'Excel comme outil puissant de Business Intelligence.

## Mission
- **Centraliser les Données** : Consolider des données issues de différentes sources (clients, réseau, commercial) dans un modèle de données cohérent.
- **Construire un Dashboard Interactif** : Mettre en place des graphiques dynamiques et des segments (`slicers`) pour permettre un filtrage simple et rapide par date, type d'abonnement ou statut client.
- **Analyser les Tendances** : Mettre en évidence des indicateurs clés comme le **taux de churn** (attrition), l'adoption de la 5G et l'évolution du chiffre d'affaires.

## Technologies & Compétences
- **Excel Avancé** : Tableaux Croisés Dynamiques, Graphiques Croisés Dynamiques, Segments, Relations entre les données (modèle de données).
- **Business Intelligence** : Création de dashboards, suivi de KPI.
